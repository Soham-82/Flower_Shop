# 🌸 Flower Shop Website

A modern and responsive Flower Shop Website developed using HTML, CSS, and JavaScript. The website provides an elegant interface for showcasing flowers, bouquets, and floral services.

## 🚀 Features

- Responsive design for all devices
- Attractive flower product showcase
- Smooth navigation
- Interactive user interface
- Contact section for customer inquiries
- Fast and lightweight website

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 📂 Project Structure

```
Flower-Shop/
│
├── html/
│   └── All HTML files
│
├── css/
│   └── Stylesheets
│
├── js/
│   └── JavaScript files
│
└── README.md
```


### Open the Project

Navigate to the project directory and open the main HTML file in your browser.

```bash
cd flower-shop
```

Open the HTML file from the `html` folder:

```bash
html/index.html
```

Or use the VS Code Live Server extension.
